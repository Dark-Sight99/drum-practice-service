## 위험 작업 여부
라벨 렌더링 보강은 노트의 시각(초) 계산을 안 건드리는 순수 텍스트 렌더링 변경 — 위험 작업 아님, Codex 모드C 생략. 마디/박선·백비트 드리프트는 조사·설명만(코드 변경 없음).

## 구현 근거(실행 결과로 확인)
- **마디/박선**: `render/layout.ts`의 `clicksPerBar = Math.round(beatsPerBar(timeSignature, 4))` 코드를 직접 확인 — 4/4에서 4클릭마다 마디선(굵게), 나머지는 박선(얇게). 의뢰인 추측이 정확함.
- **백비트 드리프트**: 실제 곡 데이터로 마디별 틱 오프셋을 분석해 "꾸준한 드리프트(마디당 약 179ms)"를 확인했고, 원본 MIDI를 앱의 import 경로와 동일한 라이브러리로 직접 파싱해 템포 이벤트가 1개뿐임을 확인 — "import가 템포 맵을 버린다"는 가설을 반증, 드리프트는 원본 데이터 자체의 패턴임을 확정. 원인(사람 연주 vs 자동채보 오차)은 미확정으로 솔직히 기록, Q-25로 더 넓은 시사점(고정 BPM 한계) 등록.
- **HH R 라벨 가독성**: 텍스트 테두리(halo) 추가 후 실제 브라우저로 밀집 구간에서 글자가 또렷해짐을 확인.
