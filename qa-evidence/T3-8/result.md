## 변경 내용
1. **솔로(S) 제거** — `app/web/src/audio/mixer.ts`의 `effectiveGain()`을 `(channel, allChannels)` 2인자에서 `(channel)` 1인자로 단순화, `muted`만 보고 `solo`는 완전히 무시. `isMusicSolo`/`setMusicSolo`(T3-4-feedback-3에서 막 추가했던 것) 삭제. `PracticeCanvas.tsx`의 `MixerRow`에서 S 체크박스·관련 prop·범례 텍스트("S = 솔로...") 삭제.
   - **범위 경계**: 백엔드 `ChannelStateIn.solo`가 필수 필드라 PUT마다 계속 `false`로 보내야 함 — 프런트 `ChannelState.solo` 필드 자체는 그대로 둠(제거하면 "공개 API 변경"이 돼 범위가 커짐). 레거시로 저장된 `solo: true` 값이 있어도 `effectiveGain()`이 완전히 무시하므로, S 체크박스가 없어져서 사용자가 끌 방법이 없는데도 "한 채널만 들림" 상태가 영원히 고정되는 버그는 안 생김.
2. **원곡 드럼 켜기 ↔ 신스 드럼 자동 전환** — `toggleDrumlessPreset()`이 `stem_drums.volume`을 0↔1로 토글할 때 `synth_drums.volume`도 반대 방향(1↔0)으로 같이 바꿈. 사용자가 그 사이 신스 드럼 볼륨을 따로 조절해뒀어도 토글 시 0/1로 덮어씀(중간값 보존은 범위 밖 — 의뢰인이 요청한 "자동 전환" 자체가 핵심).

## 모드A 지적(필수, 반영함)
`toggleDrumlessPreset()`이 `volume`만 바꾸고 `muted`는 그대로 둬서, 사용자가 M 체크박스로 신스 드럼을 미리 음소거해둔 상태에서 "원곡 드럼 켜기"를 눌렀다 다시 끄면 `volume`은 1로 복귀해도 `muted`가 여전히 true라 `effectiveGain()`이 계속 0을 반환 — "꺼짐→다시 켜짐" 복귀가 실제로는 안 들리는 버그였음. 두 채널의 `muted`를 토글할 때마다 항상 `false`로 같이 리셋하도록 수정(이 프리셋이 눌리는 순간엔 두 채널의 가청 상태를 전부 책임진다는 원칙 — 볼륨 0/1 덮어쓰기와 같은 맥락). 브라우저로 재현(신스 드럼 M 체크 → 원곡 드럼 켜기 → 끄기) → 신스 드럼 M 체크박스가 실제로 풀리고 볼륨 100%로 들리는 상태가 됨을 확인.
