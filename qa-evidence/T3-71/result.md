# T3-71 결과

## 배경 (의뢰인 요청, 2026-10-29)
T3-70(선택/드래그 중 "N마디 M박" 텍스트 표시)을 보여드렸는데 "여전히
잘 모르겠다"는 재지적. 구체적으로 두 가지:
1. "1마디 2박 1/2가 무슨뜻인지 모르겠어" — 텍스트 표현 자체가 아직
   이해하기 어려움(이번 작업에서는 그대로 두기로 확인받음 — 아래 "남은
   작업" 참고).
2. **"실선사이가 한마디잖아. 그럼 그 안에 덜선명한 선 한줄이
   얼만큼의 박자인지도 잘 모르겠어"** — 마디 경계(또렷한 실선)와 격자
   세분선(전부 똑같이 옅음) 둘뿐이라, 격자를 8분·16분으로 세분화하면
   그 안의 옅은 선들 중 어느 게 "박" 자리인지 전혀 구분이 안 됨.

2번은 명확하고 구현 가능한 지적이라 `AskUserQuestion`으로 "격자선에
박자 번호 붙이기" 방향을 시각 목업(아티팩트)으로 먼저 보여드렸고
"놔두고 진행"으로 확인받음.

## 구현 (REQ-03)
`EditorScreen.tsx`에 기존 `gridLineTicks`(격자 세분선, 옅음)·
`barLineTicks`(마디 경계, 또렷함) 사이에 **박(4분음표) 경계선** 한
단계를 추가:
- 박 간격은 박자표와 무관하게 항상 `ppq`틱 그대로 — `audio/timing.ts`의
  `ticksPerBar(ts,ppq) = beatsPerBar(ts,4) × ppq`이므로
  `beatTicks = barTicks ÷ beatsPerBar(ts,4) = ppq`로 약분됨(추가 계산
  불필요, T3-70의 `tickToBeatLabel`과 같은 근거).
- 각 박 경계에 `var(--text-muted)` 색(마디선과 같은 색)을 **투명도
  0.6**으로 그려(마디선은 불투명) — 기존 격자 세분선(`var(--border)`
  0.5 투명도, 배경과 거의 안 보일 정도로 옅음)과 마디선(불투명,
  가장 또렷함) 사이의 중간 밝기를 만든다. 3단계 밝기:
  세분선(가장 옅음) < 박선(중간) < 마디선(가장 또렷).
- 마디 시작 자리(박 1번)는 `barLineTicks`가 이미 더 또렷한 선을
  그리므로 박선을 중복해서 그리지 않고, **숫자만** "1"로 같이 보여준다.
- 각 박 경계 위쪽(그리드 맨 위, HH 행 자리)에 작은 숫자(1/2/3/4,
  마디 안에서 몇 번째 박인지)를 그려 선 자체를 안 세어봐도 바로 알 수
  있게 했다.
- 기존에 `--lane-bar`/`--lane-beat`라는 토큰이 `tokens.css`에 이미
  있었는데(연습 화면 `PracticeCanvas.tsx`의 캔버스 렌더러가 씀)
  실제 계산해보니 `--lane-beat`(#262a35)가 기존 격자 세분선
  (`var(--border)` 0.5 투명도 ≈ #232731)과 거의 같은 밝기라 구분이 안
  돼 그대로 쓰지 않고, `var(--text-muted)` + 0.6 투명도로 직접 중간
  밝기를 만들었다(연습 화면과 완전히 같은 색까지는 아니지만, 이번
  요청의 핵심인 "세 단계 밝기 구분" 자체는 달성됨 — 두 화면 색상을
  완전히 통일하는 건 이번 범위 밖으로 판단).
