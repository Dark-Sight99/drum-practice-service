## 브라우저 수동 검증 (localhost:5174, 로그인된 세션)
- **기본값**: 기존에 믹서 설정을 저장한 적 없는 곡("huibigyocha")을 열어 확인 → `드럼(원곡)` 슬라이더가 **0%**로 표시, 프리셋 버튼 라벨이 "🥁 원곡 드럼 켜기"로 표시됨(나머지 5채널은 100%). 기본값 요구사항 충족.
- **프리셋 토글**: "🥁 원곡 드럼 켜기" 클릭 → `드럼(원곡)` 슬라이더가 **100%**로 변경, 버튼 라벨이 "🥁 원곡 드럼 끄기"로 전환됨(양방향 토글 확인).
- **M(음소거) 시각 피드백**: `드럼(원곡)` M 체크박스 클릭 → 체크박스가 체크됨 + 해당 행 전체가 옅어짐(opacity 0.5, 스크린샷으로 베이스 행과 대비 확인됨). 클릭 후 되돌려 원상복구.
- **S(솔로) 시각 피드백**: `베이스` S 체크박스 클릭 → 체크됨 + 해당 행에 강조색 테두리가 나타남(스크린샷 확인). 클릭 후 되돌려 원상복구.
- 서버에 실제 PUT 요청이 가서 값이 저장됨(새로고침 없이 같은 세션 내 반영 확인 — debounced save는 T3-4에서 이미 검증된 경로 재사용, 이번 라운드에서 새로 깨진 곳 없음).
