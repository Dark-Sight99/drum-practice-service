# T3-4 게이트 피드백 1차 — 믹서 위치(빈 공간 활용)

## 배경
의뢰인이 "화면에 빈 공간이 많은데 활용하자, 믹서가 최하단에 있을 필요는 없다"고 지적. 확인해보니 `intent/04-ui-ux.md` §3 와이어프레임도 믹서를 하단 상태표시줄의 "믹서 열기" 버튼으로 계획해뒀었는데(항상 펼쳐진 큰 블록 아님), T3-4 구현 때 이 부분을 놓치고 페이지 맨 아래 큰 블록으로 만들었던 것.

## 원인
캔버스(레인)와 드럼킷 그림이 세로로 쌓여 있고, 드럼킷 그림은 `maxWidth: 320`으로 고정 — 넓은 화면(PC)에서 그 오른쪽에 빈 공간이 많이 남음.

## 수정
`PracticeCanvas.tsx`에서 드럼킷 그림과 믹서를 `flex` 행(`flexDirection: 'row'`)으로 나란히 배치(`!isPortraitPhone`일 때만, 넓은 화면). 세로 폰(`isPortraitPhone`)은 킷 자체가 원래도 안 보이므로(기존 동작, T5-1 전까지 유지) 믹서가 캔버스 바로 아래 전체 폭으로 내려옴 — 세로 폰 레이아웃 자체는 안 바뀜. 루프 상태 문구·진행바는 기존처럼 맨 아래 전체 폭 상태줄로 유지.

## 위험 분류
순수 레이아웃(CSS) 변경 — 타이밍·API·DB 변경 없음. 위험 작업 아님(T3-2-feedback-1 "보이는 마디 수"와 같은 기준), Codex 모드A만 진행.
