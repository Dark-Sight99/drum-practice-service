## 모드A 1라운드 지적(Medium, 반영함)
- **"새 세션" 경로 연타 시 셋업이 겹쳐 돌 수 있음**: 토글 버튼이 `disabled` 없이 항상 클릭 가능해지면서, `handlePlay()`의 비동기 셋업 구간(트랙·Web Audio 그래프·Tone 보이스 로딩) 중에 다시 누르면 `stopPlayback()`→새 세션 생성이 반복될 수 있음(세션 id 가드로 재생 자체는 안 깨지지만 불필요하게 반복 — 체감 버벅임 유발 가능). `isStartingRef`(동기 가드, 리렌더 전에도 즉시 재진입 차단) + `isStarting` state(버튼 `disabled` 표시)를 추가 — "새 세션" 경로 진입 시 true, 취소/실패/성공 전부 포함한 모든 종료 경로(`cleanupAbortedSetup()` 공통 처리 + 성공 경로)에서 false로 복귀.
- **브라우저 재검증**: `Audio` 생성자를 몽키패치해 호출 횟수를 세고, "▶ 재생"을 빠르게 3번 연속 클릭 → **`new Audio()` 호출이 정확히 4건**(스템 4종 — 세션 1개분)만 발생함을 직접 확인(수정 전이었다면 연타 횟수만큼 배수로 늘었을 것). 최종 상태도 "⏸ 일시정지"로 정상 재생 중, 콘솔 에러 0건.

## 모드A 2라운드 지적(Medium, 반영함)
- **1라운드 수정이 "새 세션" 경로의 동기 구간을 못 덮음**: `createTrackPlayer(...)` 호출과 `playDrumScore(...)`+`playbackRef.current` 대입이 try 블록 **밖**에 있어서, 거기서 던지면(예: Web Audio 그래프 생성 실패) `isStartingRef`/`isStarting`이 영영 안 풀려 재생 버튼이 계속 비활성 상태로 멈춤(원래 버그보다 더 나쁜 회귀). `createTrackPlayer()` 호출과 `playDrumScore()`+`playbackRef.current` 대입+플래그 해제를 전부 기존 try 블록 안으로 이동 — `tracks`도 `const`에서 `let tracks: TrackPlayer | null = null`(try 밖 선언, 안에서 대입)으로 바꿔, `createTrackPlayer()` 자체가 던져 바인딩이 아예 안 만들어지는 경우에도 `cleanupAbortedSetup()`의 `tracks?.dispose()`가 TDZ 에러 없이 안전하게 동작하도록 함(synthGain 등 기존 패턴과 동일하게 맞춤).
- **자체 발견·수정(브라우저 실행으로 재현)**: 위 이동 작업 중 `const loop = ...`도 같이 try 안으로 옮겼는데, try 밖(아래쪽 "루프면 자동 정지 타이머 안 걺" 분기 `if (loop) return`)에서 여전히 그 변수를 참조하고 있어서 실제로 **`ReferenceError: loop is not defined`**가 재생할 때마다 발생함을 브라우저 콘솔로 확인(타입체크/린트/유닛테스트는 전부 통과했었는데도 못 잡은 런타임 전용 버그 — 그래서 반드시 브라우저로 실행해 확인해야 하는 이유). `loop`도 `tracks`와 같은 패턴(`let loop: LoopBars | undefined`를 try 밖에 선언, 안에서 대입)으로 고침.
- **브라우저 재검증(새 탭에서, 과거 세션 콘솔 이력이 안 섞이게)**: 강제 실패 패치(`AudioContext.prototype.createMediaElementSource`가 한 번 던지게)로 "새 세션" 중간에 터뜨려봄 → 콘솔에 에러는 찍히지만 **재생 버튼이 다시 활성화됨**(`disabled: false` 직접 확인) → 그다음 클릭은 정상 재생. 완전히 새 탭에서 3연타 재검증 → `new Audio()` 4건만 발생(이전과 동일), 콘솔 에러 0건. 재생→일시정지→재개→리셋 전체 흐름도 새 탭에서 다시 한번 전부 정상 확인.

## 결론
기존 재생 제어 로직을 전혀 안 건드리고 버튼 구성(조건부 렌더링 + 라벨 + 배치)만 바꾼 저위험 변경 — 모드A가 두 라운드에 걸쳐 지적한 "연타 시 셋업 중복"·"동기 구간 예외 시 플래그 고착" 문제와, 그 수정 과정에서 자체적으로 발견한 `loop` 스코프 버그까지 전부 해소. 요청하신 3가지(토글 통합·리셋 이름·버튼 배치) 반영, 정상 흐름·연타 방어·강제 실패 복구까지 브라우저로 직접 확인.
