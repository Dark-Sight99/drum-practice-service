# T3-3 게이트 피드백 2차 — 숫자칸 엔터 커밋

## 배경
피드백 1차(숫자칸 "13" 버그 수정) 직후 의뢰인이 재테스트하며 "BPM 숫자를 입력하고 엔터 쳤을 때 바로 적용되게 할 수 있냐"고 요청 — 지금은 영역 밖을 클릭(blur)해야만 반영됨.

## 수정
BPM·루프 시작·루프 끝 3개 숫자칸 모두에 `onKeyDown` 추가: `Enter` 키를 누르면 `e.currentTarget.blur()`를 호출 — 이미 있는 `onBlur` 핸들러(피드백 1차에서 만든 draft→clamp→커밋 로직)를 그대로 재사용하므로 로직 중복이 없다.

## 위험 분류
순수 입력 처리 변경 — 위험 작업 아님, Codex 모드A만 진행.
