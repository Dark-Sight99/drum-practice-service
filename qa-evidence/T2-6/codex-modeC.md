- C-007 [work/T2-6/plan.md §1, 테스트 계획 5] GET은 `get_owned_song`을 사용하고 `DRUMSCORE_EDITED`를 `DRUMSCORE_RAW`보다 먼저 조회하므로, 한 편집본이 정상 저장되면 재로드 기준을 충족하는 설계입니다. 다만 API 응답을 `SongOut` 또는 204로 열어 두면 GET 이후 편집본이 실제로 선택·재로드되는지 API 계약이 불명확해질 수 있습니다. 응답 형식과 저장 직후 재조회 동작을 계획에서 확정하십시오.
