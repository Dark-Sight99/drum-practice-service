> 한 줄 요약: 2026-10-23 기획 대화에서 의뢰인이 답한 내용과 확정된 결정 기록.

# 기획 대화 기록 — 2026-10-23

## 의뢰인 원 요청
음악 파일 또는 악보 파일을 넣으면 MIDI로 변환해, 리듬게임식 시각화로 악보를 못 읽는 사람도 드럼을 연습할 수 있는 서비스. MVP 희망 기능: 오디오 분리(드럼, 추후 다른 악기), 악보·분리 오디오 → MIDI, 메트로놈·BPM 변경, 라이브러리, 드럼 연습 UI(레퍼런스 이미지 6장), 트랙별 볼륨. 스토어 비용 부담으로 웹앱 희망.

## 질의응답
| 질문 | 의뢰인 답 |
|---|---|
| 상위 목표 | 악보 보기 어려운 사람이 연습을 편하게. 우선 나부터 |
| 악보 형식 | 보유한 건 종이 실물 악보. 다양한 포맷 지원 필요 |
| 연습 화면 | 레인 + 하단 킷 점등 |
| 사용 환경 | 실제 어쿠스틱 드럼 앞, 드럼 없이 PC 앞, 이동 중 폰·태블릿 |
| 종이 악보 처리 | 사진 인식 + 수정 화면 |
| 무거운 처리 위치 | 내 PC를 처리 서버로 |
| MIDI 편집기 | 간단 편집 MVP 포함 |
| 동기화 | 내 PC에 저장하고 로그인으로 다른 기기에서 접근 희망 |
| 서버 PC | 윈도우 RTX 5060 / 맥 M1 보유. 맥 서버 선호 |

## 확인된 사실
- Electron의 메인/렌더러 분리·contextBridge·무거운 연산 별도 프로세스는 Electron 표준 패턴이 맞음. 단, 웹앱이므로 Electron 자체는 사용하지 않고 같은 원칙(UI/연산 분리)을 서버 워커·Web Worker로 적용.

## 결정
- 구조: 홈서버형 PWA (A안)
- Phase별 승인제, 연습 기록 제외, 스티킹 표시·편집 MVP 포함(REQ-12)
- 서버 기본값: 윈도우 PC (Phase 0 후 최종 결정)
- 실제로 쳐서 판정하는 기능은 확장 단계로, 구조만 대비
- 추가 기능: 구간 반복, 카운트인, MIDI 편집
- 서버 PC 결정 경위(2026-10-23 후속 확인): 1차 답변은 "맥 선호"였으나, 실제 사용 패턴(윈도우=낮 내내 사용·개발 PC, 맥=거의 안 씀)을 고려해 MVP 기간 기본값을 윈도우로 변경. 최종 결정은 T0-1 벤치마크 후 확정.
