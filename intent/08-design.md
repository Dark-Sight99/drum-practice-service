# 08. 디자인 가이드

## 1. 원칙 (의뢰인 결정, 2026-10-23)
- **다크 + 차분한 포인트색**: 어두운 배경 위에 노트만 또렷하게. 드럼 앞 1~2m 거리에서도 읽혀야 하고, 오래 봐도 눈이 덜 피곤해야 한다. 네온·글로우 같은 과한 효과는 쓰지 않는다(판정선 강조에만 약하게).
- **색 + 레인 위치로 구분**(2026-10-26 수정, 의뢰인 결정 — 아래 §3 참고): 킷 피스는 색만으로 구분하지 않는다(색약 대응)는 원칙은 유지하되, 그 대응 수단이 "모양"에서 "레인(행) 위치"로 바뀜 — 피스마다 이미 자기 레인이 따로 있어 레인 위치만으로도 색약 사용자가 피스를 구분할 수 있음. 레인 머리글 글자도 함께 쓴다.
- **멀리서 보는 화면**: 연습 화면의 글자·버튼은 일반 앱보다 크게.

| 피스 | 레인 글자 | 색 | 노트 모양 |

| 하이햇(열림) | HH | #E9C46A | 둥근 사각형 + 바깥 원 테두리 |
| 크래시 | CR | #F4A261 | 둥근 사각형 |

| 플로어탐 | FT | #9D7BD8 | 둥근 사각형 |
| 킥 | KK | #D9DDE6 | 둥근 사각형 |
- **2026-10-26 변경(의뢰인 결정)**: 원래는 피스마다 다른 모양(✕/◇/둥근 사각형/원 등, 드럼 악보 관례를 따름)이었는데, 레인이 이미 피스별로 나뉘어 있어 모양 차이가 오히려 "같은 타이밍인지 다른 타이밍인지" 순간적으로 읽을 때 방해가 된다는 피드백으로 통일하고 색으로만 구분(레인 위치가 접근성을 대신 보장 — §1 참고). 1차로 킥(KK)의 막대 모양으로 통일했다가, 실제로 써보니 "다 같은 모양으로 떨어지니 별로"라는 재피드백으로 2차로 스네어(SN)의 둥근 사각형으로 교체. 하이햇 열림/닫힘은 모양이 아니라 "치는 방법 자체"가 달라 예외적으로 테두리 원 유무를 유지. 드럼 악보 관례 연결 근거는 이번 변경으로 더 이상 적용 안 함(종이 악보 Phase는 2026-10-26 드롭돼 재검토 대상에서도 제외 — `intent/01-vision.md` "2026-10-26 갱신" 참고). 이것도 안 맞으면 피스별 원래 모양으로 되돌릴 수 있음(`git log`의 "T3-16-feedback-8" 다음 "T3-17" 커밋 이전 상태 참고).
- 셈여림(약/중/강): 같은 색에서 밝기 3단계(약 = 60%, 중 = 85%, 강 = 100%) + 강은 테두리 두껍게.
- 스티킹(REQ-12): 노트 위 R/L 글자(`--text`), 킷 점등 테두리는 오른손 실선 / 왼손 점선. 자동 추천 값은 50% 투명도. **(2026-10-25, 의뢰인 피드백 "안 맞는 게 너무 많아서" — 연습 화면 표시만 끔. 아래 REQ-12 참고.)**
- ⚠ 위 색은 초안이다. T2-3 구현 후 실제 화면 스크린샷으로 (1) 배경 대비 확인(WCAG AA 기준 3:1 이상, 그래픽 요소) (2) 색약 시뮬레이션 확인 → 의뢰인 승인 후 확정.

## 4. 타이포그래피
- 폰트: **Pretendard** (SIL Open Font License — 구현 시 공식 배포처에서 라이선스 재확인). 웹폰트는 직접 호스팅(외부 CDN 의존 금지 — PWA·오프라인은 2026-10-30 드롭, REQ-09 참고. 자체 호스팅 자체는 계속 유효한 선택이라 유지).
- 숫자(BPM, 마디 번호): `font-variant-numeric: tabular-nums` (숫자가 바뀌어도 폭이 흔들리지 않게)
| 용도 | 크기 | 굵기 |
|---|---|---|
| 연습 화면 BPM 숫자 | 32px | 700 |
| 레인 머리글 | 18px | 700 |
| 화면 제목 | 22px | 700 |
| 본문 | 16px | 400 |
| 보조 | 13px | 400 |
- 폰 세로 화면에서는 위 크기의 0.85배까지 줄일 수 있다.

## 5. 간격·모양
- 간격 단위 4px (4, 8, 12, 16, 24, 32)
- 모서리 둥글기: 버튼·카드 10px, 노트 4px
- 터치 영역 최소 44×44px. 연습 화면의 재생·BPM 버튼은 56px 이상
- 그림자 대신 `--surface` 단계로 깊이 표현

## 6. 아이콘·그래픽
- 아이콘: 오픈 라이선스 라인 아이콘 세트 1종만 사용(예: Lucide, ISC 라이선스 — 확인 후 사용)
- 드럼킷 일러스트: 자체 제작 SVG, 위에서 본 평면 + 약간 기울인 단순한 형태. 레퍼런스 이미지(EZdrummer 등)의 그래픽 복제 금지
- 움직임: 노트 낙하 외 애니메이션은 200ms 이하. 킷 점등은 짧게(약 120ms) 밝아졌다 사라짐

## 7. 적용 규칙
- 색·폰트·간격은 `app/web/src/styles/tokens.css` 한 곳에만 정의하고 컴포넌트는 변수만 참조한다.
- 이 문서와 다른 디자인이 필요하면 구현하지 말고 제안 후 승인받는다.
