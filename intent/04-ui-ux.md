# 04. UI/UX 설계

## 1. 레퍼런스 (의뢰인 제공 이미지 기반)
- 리듬게임형 낙하 노트(이미지1), 피아노롤 + 하단 건반 점등(이미지2·3) → **레인 + 하단 킷 점등**의 기반
- 드럼킷 시각 인터페이스(EZdrummer, Cakewalk 등 이미지4~6) → 하단 킷의 기반
- 주의: 레퍼런스는 구조 참고용. 타사 그래픽·로고·이미지 복제 금지, 킷 그래픽은 자체 제작(SVG).

## 2. 화면 목록
1. **라이브러리**: 곡 카드 목록, 상태 배지(처리중/완료/편집 필요), 오프라인 저장 표시, 업로드 버튼
2. **업로드**: 입력 종류 선택(음원 / 종이 악보 사진·PDF / 디지털 악보 파일) → 업로드 → 작업 진행률
3. **연습** (핵심, 아래 상세)
4. **편집**: 피아노롤 형태의 드럼 그리드(세로 = 킷 피스, 가로 = 시간), 악보 인식 결과 확인용으로 원본 사진을 옆에 표시

## 3. 연습 화면 상세
```
┌──────────────────────────────────────┐
│ 곡명   BPM [ 96 ] (원곡 120, 80%)  ▶ ⟲ │  ← 상단 바: 재생, BPM, 루프, 카운트인
├──────────────────────────────────────┤
│ │   │   ▬   │   │   │   │   │        │
│ ▬   │   │   │   │   │   │   ▬        │  ← 노트 낙하 (위→아래)
│ ▬   │   ▬   │   │   │   │   │        │
│━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━│  ← 판정선(지금 칠 시점)
│ HH  CR  SN  KK  HT  MT  FT  RD       │  ← 레인 머리글(판정선 바로 아래, T2-11
│                                        │    Phase 2 게이트 4차 피드백으로 상단→
│                                        │    하단 이동 — 실제 시선이 머무는 곳.
│                                        │    탐 레인은 T2-15에서 T1/T2→HT/MT로
│                                        │    변경(FT와 같은 의미 기반 2글자 약어로 통일).
│                                        │    킥은 T3-7(2026-10-25)에서 스네어
│                                        │    바로 다음으로 이동(원래 맨 끝이라
│                                        │    스네어·탐과 같이 보기 어렵다는 지적)
│        [ 드럼킷 일러스트 ]            │  ← 판정선 도달 시 해당 피스 점등
│   (하이햇)  (크래시)  (라이드)          │
│      (스네어)(하이탐)(미드탐)          │
│        (킥)       (플로어탐)           │
├──────────────────────────────────────┤
│ 마디 진행바 / A-B 루프 표시 / 믹서 열기   │
└──────────────────────────────────────┘
```
- **레인 순서**: 좌→우: 하이햇, 크래시, 스네어, 킥, 하이탐, 미드탐, 플로어탐, 라이드(T3-7, 2026-10-25 의뢰인 피드백 — 원래 "...플로어탐, 라이드, 킥"으로 킥이 맨 끝이었으나, 스네어·킥·탐을 섞어 치는 패턴을 한눈에 보기 어렵다는 지적으로 킥을 스네어 바로 다음으로 이동). 왼손잡이 반전 옵션은 [확장].
- **색상·모양**: 킷 피스별 고유색 + 모양. 레인 노트와 킷 점등 색을 동일하게(연결 학습). 구체 값은 `08-design.md` §3.
- **셈여림**: 노트 밝기/두께 3단계. 자동 채보 결과에는 "참고용" 표시.
- **열린/닫힌 하이햇**: 같은 레인, 열림은 테두리 노트(○) 모양으로 구분.
- **킥**: 별도 가로 막대 레인으로 표시하는 대안도 스파이크에서 비교(리듬게임 관례).
- **스티킹(R/L)** (REQ-12): ~~노트 위 작은 R/L 글자, 킷 점등 테두리로 손 구분(오른손 실선 / 왼손 점선). 자동 추천 값은 흐리게, 사용자가 지정한 값은 진하게. 상단 바에 R/L 표시 켜기/끄기.~~ **(2026-10-25, 의뢰인 피드백으로 연습 화면 표시 제거 — REQ-12 참고.)**
- **박/마디선**: 레인에 마디선(굵게)·박선(얇게) 표시 → 악보 없이도 박 감각.
- **낙하 속도**: 조절 가능(보이는 마디 수 1~4).
- **레인 폭 고정**(2026-10-25, 의뢰인 피드백): 레인이 그려지는 캔버스는 화면이 아무리 넓어도 일정 폭(현재 400px, `PracticeCanvas.tsx`의 `PRACTICE_LANE_MAX_WIDTH_PX` — 1차 520px에서 게이트 피드백 3차로 축소) 이상 넓어지지 않고 중앙 정렬 — 좌우 남는 공간은 배경색으로 채움("화면을 넓게 써도 레인이 너무 벌어져 한눈에 안 들어온다"는 지적). 캔버스 둘레에 `--border` 색 1px 테두리를 둘러 레인 영역의 경계(크기)가 보이게 함.
- **노트 테두리(halo)**(T3-11, 2026-10-25, 의뢰인 피드백 "RL 없애서 여러 개 붙어 나올 때 몇 번을 쳐야 하는지 잘 안 보인다"): 모든 노트 도형에 캔버스 배경색 테두리를 둘러, 같은 레인에 연타가 겹치거나 인접해도 경계가 구분됨.
- **반응형**: 폰 세로 = 레인만(킷은 축소 아이콘), 폰 가로·태블릿·PC = 레인 + 킷. **(T3-11, 2026-10-25) "킷은 축소 아이콘"이 T2-3~T3-4 구현에서 빠져 있던 것을 의뢰인 피드백("폰 세로에서 드럼킷이 안 보여")으로 발견·보완 — 이제 폰 세로에서도 킷을 160px(넓은 화면 320px 대비 축소)로 표시.**
- **화면 꺼짐 방지**: 재생 중 Wake Lock(지원 브라우저에서).
- **드럼 앞 사용성**: 버튼은 멀리서도 누를 수 있게 크게. 스페이스바 = 재생/정지.

## 4. 믹서 패널
트랙별 슬라이더(드럼·베이스·보컬·기타 / MIDI 드럼 소리 / 메트로놈) + M/S 버튼, 프리셋 "드럼 빼고 듣기".
