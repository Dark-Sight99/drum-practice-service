> 한 줄 요약: 윈도우 PC에서 드럼연습 서버를 켜고 끄는 방법, 로그인할 때 자동으로 켜지게 하는 방법(선택). 의뢰인이 직접 수행(T5-4).

# 서버 실행 안내 — 윈도우

이 문서는 에이전트가 아니라 **의뢰인이 직접 따라 하는** 절차입니다. 아래 스크립트들은 이미 저장소에 만들어져 있습니다(`scripts/`).

## 1. 지금 당장 켜고 끄기

PowerShell을 열고 프로젝트 폴더로 이동한 뒤:

```powershell
cd C:\Users\Jaewoo\드럼연습서비스\scripts\windows
.\start.ps1
```

이렇게 뜹니다(성공했을 때):

```
시작됨 — API PID xxxxx, 워커 PID xxxxx
접속: http://localhost:8000 (같은 PC)
원격 접속 주소는 docs/원격-접속-안내-Tailscale.md 참고
로그: C:\Users\Jaewoo\드럼연습서비스\data\logs
```

끌 때는:

```powershell
.\stop.ps1
```

**이미 켜져 있을 때 `start.ps1`을 또 실행하면** "이미 실행 중입니다"라고만 뜨고 중복으로 켜지지 않습니다 — 안심하고 여러 번 눌러도 됩니다. `stop.ps1`도 이미 꺼져 있으면 그냥 "할 일 없음"으로 끝나니 마찬가지로 안전합니다.

### 이게 실제로 뭘 하는 건가요
`start.ps1`이 켤 때마다 자동으로:
1. 데이터베이스를 최신 상태로 맞추고(`alembic`),
2. API 서버와 화면(프런트엔드)을 **같은 주소(8000번 포트)**에서 같이 띄우고,
3. 음원 분리·채보 같은 무거운 작업을 처리하는 "워커"도 같이 띄웁니다.

세 개를 따로따로 켤 필요 없이 `start.ps1` 하나로 끝입니다.

## 2. 화면까지 같이 뜨게 하려면 (최초 1회 또는 코드 바뀔 때마다)

`start.ps1`은 미리 "빌드"해둔 화면 파일(`app/web/dist`)이 있으면 그걸 같이 보여줍니다. 없으면 API만 뜨고 화면은 안 보입니다. 빌드는:

```powershell
cd C:\Users\Jaewoo\드럼연습서비스\app\web
npm run build
```

**화면(프런트엔드) 코드가 바뀔 때마다**(에이전트가 화면 쪽 기능을 추가/수정할 때마다) 이 명령을 다시 실행해야 그 변경이 실제 서버에 반영됩니다. (백엔드 쪽 코드 변경은 빌드가 필요 없고, 다음에 `start.ps1`로 다시 켜기만 하면 바로 반영됩니다.) 평소엔 신경 안 쓰셔도 되고, 작업이 끝났다는 보고를 받으실 때 필요한 경우 같이 안내해드리겠습니다.

## 3. 로그인할 때 자동으로 켜지게 하기 (선택 사항)

매번 PowerShell 여는 게 번거로우시면, 윈도우에 로그인할 때마다 자동으로 서버가 켜지도록 등록할 수 있습니다. **이건 PC의 "로그인 시 자동 실행 목록"을 바꾸는 작업이라, 에이전트가 대신 실행하지 않고 의뢰인이 직접 하시도록 남겨뒀습니다.**

등록:

```powershell
cd C:\Users\Jaewoo\드럼연습서비스\scripts\windows
.\install-autostart.ps1
```

"등록 완료"가 뜨면 끝 — 다음 로그인부터 콘솔창 없이 조용히 서버가 켜집니다(검은 창이 안 뜨는 `pythonw.exe`로 실행됨). 지금 바로 켜고 싶으면 이어서 `.\start.ps1`도 실행하세요.

해제(더 이상 자동으로 안 켜지게):

```powershell
.\uninstall-autostart.ps1
```

**자동 시작을 켜둬도 PC를 끄면 당연히 서버도 꺼집니다** — "항상 켜져 있는 서버"를 원하시면 PC 자체를 절전모드로 안 들어가게 설정하셔야 합니다(윈도우 설정 > 전원 및 절전).

## 4. 최초 관리자 계정이 없을 때

지금은 이미 계정이 있어서 해당 없지만, 혹시 나중에 DB를 새로 만들거나 관리자 계정이 전부 없어진 상황이 생기면:

```powershell
cd C:\Users\Jaewoo\드럼연습서비스
.\app\server\.venv\Scripts\python.exe scripts\create_admin.py jaewoo
```

**마지막의 `jaewoo`는 예시입니다 — `<`, `>` 기호 없이, 원하는 아이디를 그 자리에 그대로 바꿔 넣어주세요**(예: `jaewoo` 대신 본인이 쓸 아이디). 비밀번호를 물어보면(화면에 안 보이게 입력됨) 입력하시면 됩니다. 이미 관리자가 1명이라도 있으면 이 명령은 안전하게 거부됩니다(실수로 관리자를 계속 추가하는 걸 막기 위함) — 평소에 계정을 추가하실 땐 로그인 후 "관리자" 화면을 쓰시면 됩니다.

## 5. 문제가 생겼을 때

- **"가상환경을 찾을 수 없습니다" 오류**: `app/server/.venv`가 없다는 뜻 — 거의 없을 상황이지만, 생기면 알려주세요.
- **서버는 켜졌다는데 접속이 안 될 때**: `C:\Users\Jaewoo\드럼연습서비스\data\logs\server.log`(API)와 `worker.log`(워커)를 열어보면 무슨 오류가 났는지 보입니다. 캡처해서 알려주시면 확인해드릴게요.
- **원격(폰 등)에서 접속이 안 될 때**: `docs/원격-접속-안내-Tailscale.md` 참고 — Tailscale이 꺼져 있거나 서버 자체가 안 켜진 경우가 대부분입니다.
